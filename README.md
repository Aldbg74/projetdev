## Mise en ligne avec GitHub Pages

1. Créer un dépôt GitHub, par exemple `novatech`.
2. Ajouter tous les fichiers du projet à la racine du dépôt.
3. Envoyer le code sur la branche `main`.
4. Sur GitHub : **Settings → Pages**.
5. Dans **Build and deployment**, choisir **Deploy from a branch**.
6. Choisir la branche **main** et le dossier **/(root)** puis enregistrer.
7. Une fois le déploiement terminé, recopier l'URL publique ici.

## Remarque

Le formulaire est une démonstration front-end : les champs sont vérifiés avec JavaScript mais aucun e-mail n'est réellement envoyé.
